# POS Suggestions Concept

An unofficial, self-initiated design concept exploring smarter in-store suggestions for a telecom point-of-sale (POS) order screen, used by store associates on a tablet.

This project is not affiliated with, endorsed by, or connected to any company.

## Run it locally

```bash
npm install
npm run dev
```

Then open the address shown in the terminal (usually http://localhost:5173).

Built with React and Vite, styled with plain CSS, designed for a landscape tablet (1180 x 820 px).
